## Agent Brief

**Summary:** A finalized migration that was changed gets a way back in its message and the README, and `validate` prints each problem once.

- `validate` lists each problem once. Its final `Error:` line is a summary that doesn't repeat them, e.g. `Validation failed with 1 error (listed above)`.
- README "Changing your mind" (or the files section) says what to do when a finalized migration was edited, with the same steps.

- `ValidationFailedError`'s message, and how the CLI prints a listing error.
- The template README.
