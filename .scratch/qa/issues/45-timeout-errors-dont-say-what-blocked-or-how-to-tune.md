# 45: Lock and statement timeout failures don't say what was blocked, by whom, or which setting to change

**Status:** wontfix
**Category:** enhancement
**Severity:** medium
**Duplicate of:** 46
**Area:** fail

## What I did
Target `lock` (non-superuser `fail_deployer`) at migration 4, with migration 5 pending (adds `customers.slug` with a unique constraint). In another session, held a plain read lock:

```js
// scripts/hold_lock.mjs, pg via createRequire like sql.mjs
await c.query("begin"); await c.query("select * from customers"); // then keep it open
```
```sh
node scripts/hold_lock.mjs qa_fail_lock 40 "select * from customers" &
pnpm exec super-deploy deploy --target lock
```

Separately, `statementTimeout: "2s"` on a target whose pending migration has a ~10 s post-migration UPDATE.

## Expected
The message says which object the deploy waited for and, ideally, which session held it (`pg_blocking_pids` gives the pid, application name and query). It also says the deploy was rolled back and nothing changed, and that `lockTimeout` / `statementTimeout` in `super-deploy.config.ts` control this (default lock timeout 5 s).

## Actual
```
Error: data-model/migrations/00005-add-slug/schema-change.sql: PostgreSQL refused it: canceling statement due to lock timeout
```
```
Error: data-model/migrations/00008-body-len/post-migration.sql: PostgreSQL refused it: canceling statement due to statement timeout
```
"PostgreSQL refused it" reads as if the SQL were wrong. Nothing names the table, the blocker or the settings. The README never mentions `lockTimeout` or `statementTimeout`: I only found them through the config's TypeScript types.

## Notes
- The behaviour itself is good: the deploy waited up to 5 s, rolled back cleanly, and a retry once the lock was released succeeded. A concurrent second deploy was refused clearly (`Target lock is locked by attempt #3 (deploy by jonathanl, started ...); try again when it has finished`).
- Issue 13 (config options undocumented) may cover the README part. This issue is about the error message.
