## What I did

```sql

create function app.f() returns int language sql as 'select 1';
```

## Expected
Each difference indented under its object, as single-line differences are.

## Actual
```
Drift (the target differs from its recorded migrations):
  rule r1 on table app.customers:
    only on the target: other: CREATE RULE r1 AS
    ON INSERT TO app.customers DO
 NOTIFY x;
```

```
  function app.f():

 RETURNS integer
 LANGUAGE sql
```

The continuation lines start at column 0 or 1, so they read as separate entries, and with several drifted objects it's hard to tell where one ends.

### Triage, 2026-10-21

**Verification:** CONFIRMED. A hand-made rule and function on `qa` gave, in `status`, `only on the target: routine: CREATE OR REPLACE FUNCTION app.f()` followed by ` RETURNS integer`, ` LANGUAGE sql`, `AS $function$select 1$function$` and an empty line at column 0–1, and the rule's `ON INSERT TO …` / ` NOTIFY x;` the same way. The deploy refusal's one-line `Error:` is fine: it names objects only.

**Root cause:** the catalog facts for routines and rules are `pg_get_functiondef` / `pg_get_ruledef` text, which spans lines (and the function's ends with a newline). The CLI's drift listing (`driftListing` in `cli/definitions.ts`) prefixes only the first line. Rehearsal mismatches list their differences one per line the same way (`RehearsalMismatchError.differences`), so a routine difference there would break the same way.

## Agent Brief

**Category:** bug
**Summary:** Multi-line catalog definitions in drift and rehearsal-difference listings are indented under their entry.

**Current behavior:**
In `status`'s and `mark`'s drift listing, a difference whose definition spans several lines (functions, procedures, rules, and anything else PostgreSQL prints over several lines) has its continuation lines at column 0 or 1, plus a blank line after a function, so they read as separate entries.

**Desired behavior:**
- Continuation lines of a difference are indented deeper than its label line (e.g. six spaces under the four-space label line), and trailing blank lines are dropped.
- Single-line differences print exactly as today.
- Rehearsal-mismatch listings indent continuation lines the same way.
- The facts compared are unchanged; only the CLI rendering changes.

**Key interfaces:**
- The CLI's drift listing used by `status`, `mark` and the deploy refusal's warnings.
- The CLI's rendering of `RehearsalMismatchError`'s differences.

**Acceptance criteria:**
- [ ] CLI or API-level rendering test: a drifted function and rule print every continuation line indented under their difference, with no blank line.
- [ ] A single-line difference prints as today.
- [ ] A rehearsal mismatch involving a routine prints indented continuation lines.

**Out of scope:**
- Rewording catalog notation (`routine:`, `other:`, `storage=x compression=-…`); see round 1's 16.
- Which objects count as drift.
