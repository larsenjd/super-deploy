## What I did
In a fresh `init` project with a draft:
```sh
pnpm exec super-deploy deploy --target dev
pnpm exec super-deploy status --target dev
pnpm exec super-deploy deploy-draft --target dev     # in a terminal
```

## Expected
From the README, `dev` behaves as a disposable target. "Connecting to dev" says "`dev` is local and disposable", and "Disposable targets" says "A disposable target is one you may wipe and experiment on, such as your own `dev` database". So deploy-draft and rebuild should work on it, or the README should say to flag it first.

## Actual
```
Target dev: 4 migrations recorded, 0 pending          # no "(disposable)"
Error: deploy-draft only runs on disposable targets, and target dev is not disposable (flag it with disposable --target dev --set yes if it is safe to wipe): nothing changed
```
After `disposable --target dev --set yes` it works. Deleting `.super-deploy`, which the README recommends to rebuild `dev`, also loses the flag.

## Notes
The error message says what to do, so it's a small detour. The README could say so in "Getting started" or the dev section ("flag it once with `disposable --target dev --set yes`"), or `init` could flag dev itself.
