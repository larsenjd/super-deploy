### Triage, 2026-10-21

**Verification:** CONFIRMED with the built CLI. `status --target dev` on an up-to-date `dev` with no drift prints the target line and "Recent attempts", with no drift line, and exits 0. In the other states it prints `Drift: not checked (…)` or a `Drift (…)` list.

**Root cause:** the `status` command definition (`cli/definitions.ts`) prints a drift line for each "not checked" reason and for a non-empty list, and nothing when `report.drift` is an empty list. The API's `StatusReport` already tells the cases apart (`drift: []` vs `undefined`). No README or spec text fixes the output format.
