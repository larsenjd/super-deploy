### Triage, 2026-10-21

**Verification:** CONFIRMED. `postgresTarget({ env: QA_DATABASE_URL })` on line 19 gave `Error: Failed to load super-deploy.config.ts: QA_DATABASE_URL is not defined`. With `--debug` the cause is `ReferenceError: QA_DATABASE_URL is not defined` and its first frame is `at file:///…/super-deploy.config.ts:19:38`, the right line and column (type stripping keeps positions).

**Root cause:** `describeLoadFailure` (`project.ts`) adds a location only for a `SyntaxError`, read from the first line of its stack. Round 1's 52 kept runtime errors unchanged on purpose, to keep that fix narrow; nothing decided against locating them.

## Agent Brief

**Category:** enhancement
**Summary:** An error thrown while evaluating `super-deploy.config.ts` is reported with the config line it came from, as a syntax error is.

**Current behavior:**
An exception thrown while the config file runs (a `ReferenceError`, a `TypeError`, an error thrown by code in the config) is reported as `Failed to load super-deploy.config.ts: <message>`, with no line. The location is in the error's stack.

**Desired behavior:**
- When the error's stack has a frame in the config file itself, the message reads `super-deploy.config.ts:<line>: <message> in \`<source line>\``, the same shape as a syntax error, using the topmost such frame.
- Errors with no frame in the config file (thrown while an imported module loads, or without a stack) keep today's message. A function the config calls that throws is located at the config's call.
- Config validation errors (unknown setting, bad duration, missing default export) are unchanged.

**Key interfaces:**
- `loadProject` and the `ConfigError` it throws when the config fails to load (same class and code).

**Acceptance criteria:**
- [ ] API seam: a config referencing an undefined variable on line N gives a message starting `super-deploy.config.ts:N:` and containing the source line.
- [ ] CLI seam: the same on stderr without `--debug`, exit 1.
- [ ] A module the config imports that throws while it loads gives today's message.
- [ ] Syntax-error and validation messages are unchanged (existing tests pass).

**Out of scope:**
- Locations inside modules the config imports.
- Column numbers.
