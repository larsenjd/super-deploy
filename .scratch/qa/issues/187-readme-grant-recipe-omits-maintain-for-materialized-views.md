# 187: README's grant recipe gives app roles no way to refresh a materialized view (needs `MAINTAIN`)

**Status:** resolved
**Category:** enhancement
**Severity:** low
**Area:** privs
**Round:** 2

## What I did
Target `qa` set up with the README's recipe (default privileges for the deploy role
granting `select, insert, update, delete on tables` to `qa2_privs_writer`). Desired
schema adds:

```sql
create materialized view order_totals as
  select customer_id, sum(total) as total from orders group by customer_id;
```

`draft`, `finalize`, `deploy --target qa`, then as `qa2_privs_writer`:

```
refresh materialized view app.order_totals
ERROR: permission denied for materialized view order_totals
```

## Expected
README "Permissions" says how an application refreshes a materialized view it can't
own (the deploy role owns everything, and `SECURITY DEFINER` wrappers are refused).

## Actual
Nothing in the README. PostgreSQL 17+ has the `MAINTAIN` privilege for this, and it
works:

```
grant maintain on app.order_totals to qa2_privs_writer;   -- as the deploy role
refresh materialized view app.order_totals                -> REFRESH
```

## Notes
Suggest adding `maintain` to the README's example
(`alter default privileges for role deploy_role in schema app grant maintain on
tables to app_writer`) or a line saying refreshing needs it.

### Triage, 2026-10-21

**Verification:** CONFIRMED. On target `qa` with the README's default privileges (`select, insert, update, delete on tables` for the writer role), a deployed `app.order_totals` materialized view: `refresh materialized view app.order_totals` as the writer gave `permission denied for materialized view order_totals`. After `grant maintain on app.order_totals to <writer>` (as the deploy role) it gave `REFRESH`.

**Root cause:** PostgreSQL 17+ lets the owner or a role with `MAINTAIN` refresh a materialized view. The deploy role owns every object, and the README's recipe (`packages/template/README.md:427-436`) grants no `MAINTAIN`.

**Intended?** The behaviour is PostgreSQL's; the README's recipe is just incomplete. Docs brief.
