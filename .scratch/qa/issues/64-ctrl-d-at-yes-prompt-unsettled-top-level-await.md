             ^

### Triage, 2026-10-20

**Verification:** CONFIRMED, and wider than reported. In a pseudo-terminal, Ctrl-D on an empty YES prompt (`disposable --target <external> --set yes`) printed `Warning: Detected unsettled top-level await` and exited 13, with the cursor left hidden. With the embedded `dev` target the process hangs instead, and typing `YES` afterwards is ignored. Ctrl-D at the interactive menu also exits 13. Cause: `@clack/core`'s prompt creates a readline interface but never listens for its `close` event. Ctrl-D on an empty line closes readline, and the prompt promise never settles. Every clack prompt is affected (`guard/prompt.ts`, `cli/prompts.ts`).

## Agent Brief

**Category:** bug
**Summary:** Ctrl-D (end of input) at any interactive prompt cancels it, like Escape or Ctrl-C.

**Current behavior:**
At any clack prompt (the menu, option questions, confirmations, the YES prompt of guarded commands), pressing Ctrl-D on an empty line ends stdin. The prompt never settles. Depending on what else keeps the event loop alive, the process either exits 13 with Node's "Detected unsettled top-level await" warning, or hangs and ignores further input. The prompt frame stays open and the cursor stays hidden.

**Desired behavior:**
End of input at a prompt is a cancel:
- The prompt resolves as cancelled, and the cursor is shown again.
- The command takes its existing cancel path. For example, a guarded command prints "... was not confirmed (cancelled): nothing changed" and exits 1, exactly as Escape and Ctrl-C do today.
- At the menu it exits the way cancelling the menu does today.
- Ctrl-D after typing some text keeps its current behaviour (nothing happens).

**Key interfaces:**
- The CLI's prompt wrappers around clack (the YES question and the menu and option prompts). One shared wrapper should handle stdin `end` / readline `close` for all of them, rather than each prompt separately.
- clack's cancel symbol and `isCancel`, which the existing cancel paths already check.

**Acceptance criteria:**
- [ ] Pseudo-terminal: `rebuild` (or `disposable`) at its YES prompt, Ctrl-D on empty input prints the "not confirmed (cancelled): nothing changed" message and exits 1, with no "unsettled top-level await" warning.
- [ ] Pseudo-terminal: the same with an embedded `dev` target exits rather than hanging.
- [ ] Pseudo-terminal: Ctrl-D at the menu exits like Escape at the menu.
- [ ] The cursor-show escape sequence is written before exit.

**Out of scope:**
- Changing what Escape or Ctrl-C do.
- Replacing clack.
